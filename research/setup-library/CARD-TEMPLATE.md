# From concept to frozen study

Copy into the established `research-inputs/` study-card workflow when an
experiment is authorized. This template does not execute a strategy.

## Identity and question

- Library ID + concept version:
- Parent implementation/card/artifact key (or explicitly new standalone model):
- One mechanism changed; simpler control; falsification criterion:
- Asset, venue, contract, direction, timeframes; warm-up and complete window:
- Source pages; source rules versus proposed choices:

## Observable setup

- Context and level construction; which primitive definitions/versions:
- Ordered prerequisites and exact thresholds:
- Validation clock; publication/arrival assumptions and sensitivity:
- Entry type/price, first eligible action, expiry and repeat/re-arm policy:
- **Pre-entry cancellation** and consumed-target policy:
- **Hard stop** price/buffer, executable gap behavior and stop priority:
- **Post-entry thesis failure** and independent time exit, if any:
- Target selection/allocation; opposing-zone constraints; minimum after-cost R:
- Conflict/overlap handling, incomplete-data behavior, unknown state:

## Sizing and accounting

- Fixed notional or fixed risk (never silently mix); equity for DD:
- One/multiple positions; shared capital, occupancy and skipped signals:
- Fees, spread/slippage, funding, margin and liquidation coverage/limitations:
- Candle ambiguity and resting-limit fill assumptions:
- Open inventory and exposure at cutoff; realized and marked results:

## Verification and evidence

- Exact own-parent baseline parity before variants:
- Prefix replay / future poisoning / no backdated pivots or zones:
- Hand trace: source → decision → order → fill → exit with timestamps:
- Independent fills/fees/ownership/DD/monthly reconciliation:
- Frozen parameter count and trial register update:
- Baseline-adjacent W/L counts/dollars, average loss, net, R/expectancy, PF,
  DD, monthly deltas, concentration, missed winners and duration:
- Study-specific qualification screen, untouched/forward evidence boundary:
- Output/input/code seals and local saved feature/map identity:

## Library evidence update after the study

Attach the immutable card/findings/verification paths and exact scope:
`library ID, concept version, implementation hash, asset/venue, timeframe,
window, execution assumptions, baseline, result, qualification, limitations`.
State whether this directly tests the definition or is only an adjacent control.
Keep older results and failed variants; do not rewrite the original concept.
