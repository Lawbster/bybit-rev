# Context and entry modifiers

These require a parent entry; none is permission to enter by itself.

## CTX01 — Protected external structure versus internal pullback

**Source:** MS21 pp8–17; PA29 pp15–20. The swing causing a continuation break
becomes protected; internal countertrend action can occur without its failure.
**Observable states:** insufficient context; external trend intact; internal
pullback; protected-swing breach; reclaim pending; opposite structure confirmed.
Publish each transition only when its confirming evidence is available.

**Use / validation:** join last available state to original entry opportunities,
on the same asset or another asset such as BTC→HYPE/ETH. Evaluate a damage veto
separately from a positive-alignment requirement and recovery permission.
**Invalidation / release:** explicitly define when warning ends and when trend
is actually repaired; a single reclaim is not automatically full recovery.
**Risk / target:** inherited from the parent; does not remove stops or increase size.

**Unresolved:** external/internal hierarchy, pivots, close rule, release and
stale context. Existing BTC percentage-change studies do not validate this
classifier. Missing cross-asset bars produce unknown, not favorable alignment.

## CTX02 — Completed Monday range

**Source:** D9 pp1–5. Current/prior week's completed Monday extremes provide
context; source explicitly calls this context, not a complete trading method.
**Sequence:** completed Monday → known high/low → later interaction with an
eligible extreme → parent setup validation → opposing objective if still valid.

**Entry:** parent PA01/PA02/PA04, never “Tuesday means buy”. **Invalidation:**
expired week identity, consumed target, failed parent structure or unavailable
session inputs. **Target:** declared opposite Monday extreme or parent target;
choose before entry, not whichever later hits.

**Unresolved:** session timezone, which current/prior extreme wins precedence,
untouched definition and rollover. UTC is a proposal, not given in the lesson.
Full Monday extrema cannot be used intraday Monday. “Avoid Monday” is a separate
source preference to test against identical unfiltered parent opportunities.

## CTX03 — Power of Three / open-and-range context

**Source:** D11 pp2–7; S29 pp8–10. Accumulation/open context, old-extreme raid,
then expansion toward an already existing opposing extreme. Source requires
other confluence; a three-box chart appearance is insufficient.

**Sequence:** define consolidation/open region from past data → old-extreme
excursion → parent reversal/reclaim validation. Expansion belongs to outcomes,
not a prerequisite retrospectively applied to the early entry.
**Entry / stop / target:** inherited from the selected parent, with opposing
known liquidity target. **Invalidation:** parent fails or range/open/target
identity expires; no unlimited waiting for the story to become true.

**Unresolved:** consolidation, sessions, minimum old-level age, reversal and
expiry. Neither “accumulation” nor “distribution” proves who held positions.
Session-only indicator filters and the source PO3 narrative are different tests.

## MOD01 — HTF parent zone, LTF confirmation

**Source:** E43 pp28–30; D3 pp6–8; MS21 p11; STC18 p14.
**Sequence:** HTF zone already qualified → price enters it → subsequent LTF
sweep/structure confirmation within the parent → eligible entry. Distinguish
the outer range sweep that created the setup from the secondary sweep in-zone.

**Validation:** every input has its own closed-bar/arrival clock. **Entry:**
next executable price after LTF validation. Compare to first HTF touch using
the same parent opportunities, counting never-confirmed and missed moves.
**Invalidation:** failed parent cancels LTF attempt; hard stop at declared
LTF sweep or parent boundary (different variants). **Target:** known parent objective.

**Unresolved:** timeframe pair, in-zone containment, LTF confirmation, expiry
and stop. Do not claim a tighter stop improves risk without measuring extra
stop-outs, gap exposure and missed fills. Source timeframe examples are not
universally optimal settings.

## MOD02 — 0.705 OTE entry location

**Source:** D1a pp2–9. The 0.705 retracement is taught within a qualified OB;
personal variant additionally needs sweep + MSB.
**Sequence:** causally complete impulse endpoints and qualifying zone → freeze
retracement price → order eligible only if that price is inside the zone → retest.
For upward leg [L,H], proposed 70.5% retracement is H−0.705(H−L); mirror for
downward leg. Check source chart orientation when freezing the card.

**Invalidation:** parent failure, consumed target, expiry or endpoint revision
requiring a genuinely new setup. Never recompute the original order from the
eventual highest high. **Stop/target:** inherited, unless explicitly changed.

**Unresolved:** endpoint confirmation, order expiry, gap/queue fills and minimum
R. Compare edge entry with the same parent/stop/target before searching Fib
ratios. “Optimal” in the name is not a measured optimality claim.

## MOD03 — Zone freshness, dwell and return shape

**Source:** SD52 p9; PA29 pp13,24–27; STC18 pp14–15.
**Observable fields:** first versus repeated return, time away, in-zone dwell,
penetration, return speed/overlap, intervening confirmed swing still intact,
and formation impulse/volume. Different sources emphasize different subsets.

**Use / validation:** record features at original parent opportunities, then
test one qualifier at a time against that parent's unfiltered baseline. An
optional source quality list must not become an untested mandatory AND-stack.
**Invalidation:** this is pre-entry quality, not a protective stop. Post-entry
failure-to-react belongs to EXIT01; don't label a return bad using its later loss.
**Target/risk:** parent unchanged for a clean quality test.

**Unresolved:** exact quality definitions, bins/thresholds, visit identity and
warm-up. “Liquidity inducement” is an intermediate swing/equal-level proxy,
not observed stops. No proof that more touches or longer dwell always predict failure.

## MOD04 — Imbalance with structure/origin-zone confluence

**Source:** SD52 pp34–43 versus D5 pp2–7. Wick-separated gap and broad expansion
void are separate types. SD52 explicitly warns against FVG-only entries.

**Sequence:** declared gap/impulse evidence becomes known → associated structure
and origin zone qualify → parent retest/entry. A proposed three-bar bullish
gap uses third low > first high and publishes after third close; bearish mirror.
This formalization is not D5's entire multi-bar narrative.
**Invalidation:** parent failure, filled/expired gap before required interaction
or bad input; preserve partial-fill state as-of. **Stop/target:** parent.

**Unresolved:** gap type, minimum size, overlap/distance confluence, fill rule,
expiry and HTF precedence. Do not select only gaps that eventually filled;
no source narrative guarantees a retrace. Compare parent with/without this
modifier before any gap-only trade study.
